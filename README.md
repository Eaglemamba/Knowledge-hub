# Knowledge Hub

Personal knowledge index — a meta-layer connecting all my repos into one searchable system.

## What This Is

Not a second brain app. Not a note-taking system. Just an **index** that tells Claude Code (or me) where to find what across 10+ repositories spanning pharma operations, AI, health, and personal development.

## Quick Start

Open `CLAUDE.md` for the full map and usage instructions.

## Structure

```
cross-notes/    → Insights that span multiple repos
indexes/        → Summary indexes of each repo's contents  
templates/      → Note templates
```
