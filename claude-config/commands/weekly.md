Start my weekly review.

1. Create a new file at `coo-track-os/reviews/weekly/` named with the current ISO week: `YYYY-Www.md`
2. Copy the template from `coo-track-os/reviews/weekly/_template.md`
3. Read this week's daily check-ins from `coo-track-os/reviews/daily/` to reference during the review
4. Walk me through each section, referencing patterns from my daily check-ins:
   - Signal vs. noise — what moved the needle vs. what was busy
   - Cross-functional touchpoints this week
   - One stakeholder relationship to invest in next week
   - Where time leaked into low-leverage work
   - One strategic insight
   - Content pipeline — anything worth developing into a post
   - COO-track pulse check
   - Next week's top 3 priorities
5. After I answer each section, write my response into the file
6. At the end, ask if `tracking/stakeholder_map.md` or `tracking/content_pipeline.md` need updates
7. Target 30 minutes total
